# Input data and metadata

GEO accession: pending.

The figure workflow requires an annotated Seurat object with the `Nanostring` assay and metadata fields `sample_id`, `fov`, `Final_celltype`, `CenterX_local_px`, and `CenterY_local_px` (and any additional fields required by later analyses). `RT_region` may be used when present. FOV 4 is the non-response region and FOV 6 is the response region. Pixel size: 0.12 µm; primary radius: 25.39 µm; extended niche radius: 101.56 µm.

No patient data or data objects are distributed in this draft. Confirm institutional approval and de-identification before releasing metadata, expression data or images.
